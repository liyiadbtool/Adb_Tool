```

        ▼
```

## 3. 线程模型（最容易踩的地方）

| 线程 | 干什么 | 注意 |
|---|---|---|
| UI 线程 | WinForms 消息循环、`PumpOutput`、所有 `PostWebMessageAsJson` | **任何 adb 调用都不能放这里**（会冻窗口） |
| worker[0..2] | 每个输入槽一个，跑 `Dispatch` | `[ThreadStatic]` 的 `CUR_SLOT`/`CMD_OK` 只在这里可靠 |
| `syn-bg-probe` | `Bg.Loop`，每 80ms 检查一次"要不要探测设备" | `Request()` 只投意愿，`TryTake()` 永不阻塞 |
| `track-devices` | 长连 5037 订阅设备事件 | 断了要重连，不能阻塞 UI |
| `cast-<slot>` | 每格投屏一帧一帧抓 | 最外层 try-catch，异常必须置 `Stop`+`Err` |
| ThreadPool | `adb` 的 stdout/stderr 回调 | 这里 `CUR_SLOT` 恒为 0，必须靠 `SlotHint` |

**三条铁律**：
1. 新的后台能力不要直接读写 `App.DEVN/DEVID/OFFLINE`——统一回 UI 线程改（参考 `FinishInvoke`）。
2. 线程池回调里写 Console，先 `GuiSink.SlotHint = slot`。
3. 关闭路径上不要做阻塞调用（`OnFormClosing` 的教训见 `GuiWeb.cs:1496`）。

## 7. 七个关键机制（专题）

### 7.1 并发的真实形状
- 3 槽，`SLOT_COUNT=3`（`Prefix.cs:120`）；前端 `+` 加框带 `slot`。
- 槽位互斥：`_busy[slot]`；停止只杀本槽 `KillRunning(slot)`。
- 长等待命令额外有 `GUISTOP`（sleep 轮询 kill 不到）。
- 截帧录屏按槽判断 `REC_GRAB_RUNNING[slot]`，否则全局标志会误停别的槽。

### 7.2 输出管线
- `GuiSink` 队列上限 50000，超限丢最早并**上报丢了多少**（沉默截断比丢行更糟）。
- 自适应节拍：有积压 33ms、常态 50ms、空闲 250ms；有新行瞬间 `WakePump` 拉回 33ms。
- 前端逐行 `appendChild`，**未用 DocumentFragment**；`trimLog` 每行 `querySelector`。

### 7.3 桥协议
- 前端→后端约 45 个 kind，后端→前端约 35 个（全集见 `GuiWeb.cs:1296-1763` 的 `case`）。
- 手拼 JSON + `GetField/GetInt/Json()`，**无 schema**：加字段靠约定，漂移靠门禁抓。
- 约定：`themeget` 一次回推 theme + accent + prefs 三条，是"设置重启回默认"的根治点。

### 7.4 投屏双引擎
- **内置通道**：`screencap -d N`（raw 优先，失败或更慢则 png）→ 本机转 JPEG → 本地 HTTP `/live/<slot>` multipart → `<img>`。上限 1~5fps，是协议天花板。
- **scrcpy 内嵌**：h264 → SDL 窗口 → `SetParent` 塞进 Panel；页面只上报**比例**（不是像素，避开 DPI/Zoom 错位）；全屏/退出通过 `castEnterFull/castExitFull` 重报，C# 侧 `ScrcpyEmbedPlace` 识别退化区域隐藏 Panel。
- 六格固定映射 `[0,4,1,3,9,10]`（`ui.html:6832`）。
- 缩略条用 `/snap/<slot>` 短连接，避免浏览器同源连接数被长连接占满。

### 7.5 前端分层注入
- 注入脚本只做"删旧块 + 插到 `</style>`/`</script>` 前"，所以**后层天然覆盖前层**，这就是"顺序不能乱"的物理原因。
- V17 用"包一层"：保存 `window.hideSplash` 再替换，不动原实现。

### 7.6 稳定性四件套
`Bg`（不阻塞 UI 的探测）+ `DeviceWatcher`（订阅而非轮询）+ `Reconnect`（渐进退避/先 reconnect 再重启）+ `Wadb`（瞬断抑制）。四者都围绕同一个现场问题："拔插/息屏后再也搜不到设备"。

### 7.7 单文件与出包
`Embed` 把 ui.html / 3 个 dll / 默认 ini 编进 exe，**外置优先**；`release.py` 出三包（完整/最小/单文件），并默认先跑门禁（防"单项全绿但整页空白"）。
