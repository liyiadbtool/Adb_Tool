# 白天 / 黑夜主题按 Edge 分层重构（设计记录，未改代码）

> 2026-11-28 · 玻璃主题维持现状，本轮只做 `dark` / `light` / `eye` 的分层设计
> 目标：把"底色 / 卡片 / 次级"这种**组件语义**，换成"窗口 / 框架 / 内容 / 浮层"的**层级语义**，
> 这样以后想给某一层填主题色（比如标题栏上品牌色），只改一个令牌，不会牵一发动全身。

---

## 一、现状的三个问题

```css
/* 现在每套主题只有三个面 */
--bg      窗口底 / 页面底
--surface 卡片 / 面板
--surface-2 次级面（hover、输入框）
```

1. **没有"层"的概念**：标题栏、左侧导航、内容区、弹窗，全都复用 `--surface`。
   想给标题栏单独上色 = 要么新加变量，要么改 `--surface`（连带所有卡片一起变）。
2. **深色下层级是"抬升"（#000 → #1c1c1e → #2c2c2e），浅色下是"下沉"（#f2f2f7 → #fff）**。
   两种方向混在一个 `--bg/--surface` 里，读代码时判断不出"谁在谁上面"。
3. **边缘靠 `--border` 一个值**，但 Edge 里不同层的边界强度不同（标题栏与内容之间最明显，卡片之间最弱）。

---

## 二、Edge 的分层模型（对齐目标）

```
L0  窗口底        window base       整窗一张，最"远"
L1  标题栏 + 页签  chrome            贴住 L0，与它同色系、略抬亮
L2  左侧导航       rail              与 L1 同材质带，右侧一条分隔线
L3  内容区         content           承载日志/终端/表格，对比度最高
L4  浮层           overlay           菜单/弹窗，比 L3 更亮/更暗 + 大投影
L5  遮罩           scrim             只用于模态
```

**Edge 的三条规律**

| 规律 | 说明 |
|---|---|
| 亮度单调 | 深色主题：层越高越亮；浅色主题：层越高越白（L0 最灰） |
| 一处分隔 | 只有 L1/L2 与 L3 之间有一条强分隔线（1px，`--rim-strong`），卡片之间用弱线 |
| 一处投影 | 只有 L4 有大投影；L1/L2/L3 之间不用阴影 |

## 三、令牌设计（建议命名）

### 3.1 面（背景）

```
L0  --l0-bg          窗口底
L1  --l1-bg          标题栏 / 页签
L2  --l2-bg          左侧导航
L3  --l3-bg          内容区（日志、终端、表格所在的底）
L4  --l4-bg          浮层（弹窗、菜单）
L5  --l5-scrim       模态遮罩
    --l3-sunken      内容区里的"内凹块"（代码块、输入框）
```

### 3.2 线

```
--rim-weak          卡片之间、列表分隔（原 --border）
--rim-strong        L1/L2 与 L3 之间的那条强分隔（Edge 的关键细节）
--rim-inner         浮层/卡片的 1px 内描边（浅色下提亮、深色下提暗）
```

### 3.3 字（按层给，而不是全局一套）

```
--l1-text / --l1-text-dim      标题栏（压在 L1 上）
--l3-text / --l3-text-dim      内容区（压在 L3 上）
--l4-text / --l4-text-dim      浮层
```

理由：以后若把 L1 填成品牌色（比如深蓝），`--l3-text` 的灰阶不一定在 L1 上达标，
分层给文字色才能保证任何配色下的对比度。

### 3.4 给"后续填主题色"留的扩展位

```
--l1-tint           标题栏品牌色叠加层（默认 transparent）
--l1-tint-strength  叠加强度（0~1，默认 0）
--l2-tint           导航品牌色叠加层（默认 transparent）
```

用法：将来想给标题栏上品牌色，只写
`--l1-tint: rgba(0,102,204,.10)`，L1 立刻带品牌调，且不影响 L3 内容区。

## 四、三套主题的取值（建议值，供实施时对照）

| 令牌 | dark | light | eye |
|---|---|---|---|
| `--l0-bg` | `#000000` | `#f2f2f7` | `#fdfaf3` |
| `--l1-bg` | `#1c1c1e` | `#f7f7fa` | `#fffdf7` |
| `--l2-bg` | `#161618` | `#f2f2f7` | `#f8f4ea` |
| `--l3-bg` | `#1c1c1e` | `#ffffff` | `#fffdf7` |
| `--l4-bg` | `#2c2c2e` | `#ffffff` | `#f6efe0` |
| `--l5-scrim` | `rgba(0,0,0,.62)` | `rgba(0,0,0,.34)` | `rgba(48,40,26,.38)` |
| `--rim-weak` | `rgba(84,84,88,.60)` | `rgba(60,60,67,.29)` | `rgba(120,105,75,.28)` |
| `--rim-strong` | `rgba(235,235,245,.16)` | `rgba(60,60,67,.18)` | `rgba(120,105,75,.20)` |

**与现状的差异只有一处是"改视觉"的**：深色下 `--l2-bg` 比 `--l1-bg` 略暗（`#161618`），
让侧栏"退后"一层；现在侧栏和标题栏同色，靠边框区分。浅色下 `--l2-bg` 回到窗口灰（`#f2f2f7`），
`--l3-bg` 纯白——这正是 Edge 浅色的观感：侧栏是灰、内容是白。

## 五、迁移方式（不破坏现有 200+ 处引用）

**第一步：加别名，不改用法**

```css
:root[data-theme="dark"]{
  --l0-bg:#000; --l1-bg:#1c1c1e; ... /* 新令牌 */
  /* 旧名指过去，现有组件样式一行不用改 */
  --bg:var(--l0-bg);
  --surface:var(--l3-bg);
  --surface-2:var(--l4-bg);
  --border:var(--rim-weak);
}
```

**第二步：按区域逐个换到新令牌**

```
① 标题栏 .tb / 页签           → --l1-bg + --l1-text
② 左侧导航 .qnav              → --l2-bg + --rim-strong 右边界
③ 内容容器 .quick-body 等      → --l3-bg
④ 浮层 .v15-pop / #cf-panel    → --l4-bg + --shadow-lg
⑤ 模态遮罩                    → --l5-scrim
```

每换一处都能独立截图对比，不会"改一半全乱"。

**第三步：删别名**（全部换完后），旧令牌不再保留，避免两套并存。

## 六、风险与注意

```
① 深色下 L2 比 L1 暗，会让侧栏"看起来凹进去"
   → 这是 Edge 的做法，但要实测是否与本工具的重阴影风格冲突
② 浅色下 L3 纯白 + L0 灰，需要 --rim-strong 撑住边界，否则分不清内容区边界
③ 按层给文字色会增加令牌数量（约 +6 个/主题），但换来"任意填色都达标"
④ eye（护眼）本身是暖白变体，分层后必须保持暖调，不能借用 light 的冷白
⑤ 玻璃主题不参与本次分层（保持现状，避免两套规则打架）
```

## 七、实施顺序（后续做的时候）

```
1. 加三层令牌 + 别名（纯新增，零视觉变化）→ 截图确认无差异
2. 换标题栏 → 截图
3. 换导航（含 --rim-strong 分隔线）→ 截图
4. 换内容区 → 截图
5. 换浮层 → 截图
6. 删别名，跑门禁（会新增令牌名，需登记）
7. 三套主题 × 三档窗口宽度截图对比
```

**验收标准**：白天/黑夜在"不看边框、只看底色"时，仍能一眼分出 标题栏 / 侧栏 / 内容 / 浮层 四层。
