## 维护约定

1. 加功能 → 在 **本表** 和 `_check_features.json` 各加一条；
2. 删功能 → 两处都删，并在 `docs/项目规则.md` 记一条"为什么删"；
3. 改功能的落点（改名/搬家）→ 同步改 JSON 里的 `anchors`，否则机检会红（这是故意的）。
4. 改项目根 `cmds.ini` → **必须同步 `adb_log_gui/cmds.ini`**。`build_gui.bat` 只在该文件缺失时才从上级复制，不会自动同步；而 `dist` / `dist_min` 的外置 ini 与单文件版内嵌的 `adb.default.cmds.ini` 都取自它。漏同步会让新命令在成品里静默失效，且 16 项门禁查不出来（2026-11-14 踩过一次，已加 `cfg.cmds_sync` 机检）。
5. 改 `#page-*` 结构 → 必须同步 `377/_test_structure.py` 的 `PAGES` / `KEY` 与页签顺序断言（五个页、UI 在投屏右侧）。

### 15.4 参考 Edge 的调研结论
