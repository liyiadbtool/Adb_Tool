### 2.1 两个失败项的定性（均为环境，非代码缺陷）

| 失败 | 根因（已实测确认） | 复现条件 | 处置 |
|---|---|---|---|
| `Liquid Glass 17/20` | 系统「透明效果」关闭 → Edge 报 `prefers-reduced-transparency: reduce`（单独探测验证 `reduced-transparency=true`）→ ui.html 玻璃层按无障碍设计退化为纯色：`.frame` 用 `--surface`、`.tabs` 无 `backdrop-filter` | 任何关闭了透明效果的 Windows 机器 | 打开系统透明效果即转绿；**不改代码**（改代码就等于取消无障碍降级） |
| `GUI 自检 45/46` | 唯一红项 `scrcpy 探测覆盖 winget Packages 目录` —— 本机未安装 winget 版 scrcpy，31 个候选里没有 `Genymobile.scrcpy` 路径 | 未装 `Genymobile.scrcpy` 的机器 | `winget install Genymobile.scrcpy` 即转绿 |
