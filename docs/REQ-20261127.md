## D10 指令卡片图标不对 —— 根因排查

**现象**：指令卡片的图标与命令含义不匹配。

**彻底排查结果**：

1. **所有指令卡片用的是同一个图标** —— 播放三角 ▶（`ICON_PLAY`）。

   `ui.html:14770` 等 4 处卡片构造里：

   ```js
   html += '<div class="qhead"><span class="qico">' + ICON_PLAY + '</span>'
   ```

   `ICON_PLAY` 定义（`ui.html:14321`）：

   ```js
   var ICON_PLAY = '<svg viewBox="0 0 24 24" ...><path d="M6 4l6 4-6 4z" .../></svg>';  // 一个实心三角
   ```

2. **没有"按命令/类别区分图标"的机制**。

   图标只在**执行状态**变化时切换（`setCardIcon`，`ui.html:14326`）：

   ```
   默认  = ICON_PLAY（▶ 播放三角）
   running = ICON_STOP / ICON_SPIN
   done    = ICON_DONE（✓）
   error   = ICON_ERROR（✗）
   ```

   没有任何"打开后台用齿轮、查询用眼睛、下载用箭头"这类**类别→图标**映射。

3. **结论**：所以「配置中心后台」「打开日志设置」「账号助手」这类**不是"跑一条命令"、而是"打开一个页面/后台"**的卡片，也显示 ▶ 播放三角 —— 语义对不上，就是"图标不对"的根因。

**可能的两种"不对"（需你确认是哪一种）**

```
A. 播放三角 ▶ 对不上"打开后台/设置"这类动作 → 需要按命令类别配图标
B. 某个图标渲染成了方块/乱码（字体缺失，字形 fallback）→ 是另一类问题
```

**建议修法（记录，未执行）**

```
① 给卡片加"类别图标"映射：cat / cmd 前缀 → 对应 SVG
   （后台/设置→齿轮、查询/信息→眼睛、下载/导出→下箭头、开关→toggle…）
② 状态图标（running/done/error）保持不变
③ 若 B 类：检查图标 SVG 是否用了设备字体里没有的 unicode 字形
```

**优先级**：中（不影响功能，但影响识别与观感）

## D11 任务栏 hover 小弹窗显示"原始图标"（不是黑猫）——根因排查

**现象**：鼠标悬停在任务栏（dock）图标上，小弹窗/缩略图显示的是**原始/默认图标**，不是自定义黑猫图标。位置右上角。

**彻底排查结果**（代码 + 构建脚本 + 文件系统三处核实）：

1. **`ShowIcon = false`**（`GuiWeb.cs:167`）：窗口关闭了图标显示。

2. **图标加载路径取错**（`GuiWeb.cs:269 TrySetCatIcon`）：

   ```csharp
   string icp = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, "adb_Tool.ico");
   // BaseDirectory = dist\ → 找 distdb_Tool.ico
   ```

   但构建脚本 `build_gui.bat:206` 只把 ico 复制到 `dist\internaldb_Tool.ico`：

   ```bat
   copy /y "%~dp0adb_Tool.ico" "%DIST%\internal" >nul
   ```

   实测文件系统：

   ```
   distdb_Tool.ico          不存在   ← TrySetCatIcon 要找的
   dist\internaldb_Tool.ico 存在（32187 字节，与源码 ico 一致）
   ```

   所以 `File.Exists(icp)` **恒为 false** → 永远走兜底
   `Icon.ExtractAssociatedIcon(exe)`（从 exe 提取内嵌图标）。

3. **exe 内嵌图标存在**：`/win32icon:adb_Tool.ico`（`build_gui.bat:115`）已生效，
   exe 内确实含 PNG 图标数据。

**结论**：任务栏 hover 小弹窗的图标来自窗口图标（WM_GETICON / Form.Icon）。
当前链路是：

```
ShowIcon=false + TrySetCatIcon 路径取错(找不到 distdb_Tool.ico)
→ 兜底 ExtractAssociatedIcon(exe) 提取的图标尺寸/变体不对
→ 任务栏小弹窗退而显示"原始/默认"图标
```

**建议修法（记录，未执行）**

```
① TrySetCatIcon 路径改为 internaldb_Tool.ico（或两个路径都试）
② 确认 ShowIcon=false 的必要性：它只隐藏标题栏图标，不应影响任务栏；
   若希望任务栏也显示黑猫，确保 Form.Icon 被正确设置为黑猫
③ 兜底 ExtractAssociatedIcon 返回后，验证是否取到正确尺寸的黑猫图标
```

**优先级**：中（不影响功能，影响品牌观感）
