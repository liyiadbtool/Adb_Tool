## R3 新增「打开日志设置」指令

**要求**：新增一条指令，直接打开设备上的日志设置页。

**用户提供的信息**

```
包名  com.gxa.car.systemlog
Activity  未提供
```

**建议写法（二选一，需确认）**

```ini
# 方案 A：已知 Activity
[cmd.stlogset]
desc = 日志设置：打开车机日志设置页
group = SynTestUtil
usage = stlogset
run = shell am start -n com.gxa.car.systemlog/<Activity>

# 方案 B：只知道包名，用 monkey 启动入口 Activity
[cmd.stlogset]
desc = 日志设置：打开车机日志设置页
group = SynTestUtil
usage = stlogset
run = shell monkey -p com.gxa.car.systemlog -c android.intent.category.LAUNCHER 1
```

**推荐方案 B**：只要包名即可工作，不依赖具体 Activity 名；
缺点是输出是 monkey 日志，不是干净的 am 结果。

**待确认**

2. 指令名用 `stlogset` 还是别的（避免与 R1 删除的 `stlogcfg` 混淆）
3. 归到「配置入口」分组还是「信息查询」

## D10 指令卡片图标不对 —— 根因排查

**现象**：指令卡片的图标与命令含义不匹配。

**彻底排查结果**：

1. **所有指令卡片用的是同一个图标** —— 播放三角 ▶（`ICON_PLAY`）。

   `ui.html:14770` 等 4 处卡片构造里：

   ```js
   html += '<div class="qhead"><span class="qico">' + ICON_PLAY + '</span>'
   ```

   `ICON_PLAY` 定义（`ui.html:14321`）：

   ```js
   var ICON_PLAY = '<svg viewBox="0 0 24 24" ...><path d="M6 4l6 4-6 4z" .../></svg>';  // 一个实心三角
   ```

2. **没有"按命令/类别区分图标"的机制**。

   图标只在**执行状态**变化时切换（`setCardIcon`，`ui.html:14326`）：

   ```
   默认  = ICON_PLAY（▶ 播放三角）
   running = ICON_STOP / ICON_SPIN
   done    = ICON_DONE（✓）
   error   = ICON_ERROR（✗）
   ```

   没有任何"打开后台用齿轮、查询用眼睛、下载用箭头"这类**类别→图标**映射。

3. **结论**：所以「配置中心后台」「打开日志设置」「账号助手」这类**不是"跑一条命令"、而是"打开一个页面/后台"**的卡片，也显示 ▶ 播放三角 —— 语义对不上，就是"图标不对"的根因。

**可能的两种"不对"（需你确认是哪一种）**

```
A. 播放三角 ▶ 对不上"打开后台/设置"这类动作 → 需要按命令类别配图标
B. 某个图标渲染成了方块/乱码（字体缺失，字形 fallback）→ 是另一类问题
```

**建议修法（记录，未执行）**

```
① 给卡片加"类别图标"映射：cat / cmd 前缀 → 对应 SVG
   （后台/设置→齿轮、查询/信息→眼睛、下载/导出→下箭头、开关→toggle…）
② 状态图标（running/done/error）保持不变
③ 若 B 类：检查图标 SVG 是否用了设备字体里没有的 unicode 字形
```

**优先级**：中（不影响功能，但影响识别与观感）
