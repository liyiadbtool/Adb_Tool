# 白盒检查报告（对照 R1~R11）

日期：2026-11-26
范围：`_cs/*.cs`（C# 后端）、`adb_log_gui/webview2/ui.html`（前端）
性质：**仅记录，未修复**。按影响面排序。

## 一、违反 R1（复用优先）—— 同一功能多套实现

| 编号 | 功能 | 现有实现 | 影响面 | 严重度 |
|---|---|---|---|---|
| W-01 | 截图 | `:shot`（AdbCmd 重定向，可用） / `:shotopen`（自拼命令行，写不出文件） | 一键截图并立即打开直接失败；用户需退回使用 :shot | **高** |
| W-02 | 调 adb | `AdbCall`（argv + 转义）/ `RunAdbRawEx`（拼串走外壳）/ `DoShotOpen`（第三种拼法） | 三条通道的 `-s` 规则、引号规则、超时规则各不相同 | **高** |
| W-03 | 设备号选择 | `BuildPsi` 里的 isGlobal 白名单 / `RunAdbRawEx` 里复制的一份 | 新增全局命令时只改一处，另一处会误带 `-s` 报错 | 中 |
| W-04 | 导出目录 | `DefaultOutDir` / `OutDirFor(cmdId,kind)` / `CUR_EXPORT_ID` 隐式 id | 曾导致"设了路径不生效"，现以 kind 兜底 | **高**（已修） |
| W-05 | 命令成败判定 | `CMD_OK` / `OkLocal()` / `DispatchChecked` / 前端 `OK_N/FAIL_N` | 四套规则并存，边界靠注释维持 | 中 |
| W-06 | 停止/清理进程 | `KillRunning(slot)` / `KillAllRunning` / `StopWorker` + `KillDeviceSidePersistent` | PC 端与设备端清理分散，容易漏一端 | 中 |
| W-07 | 超时 | `CALL_TIMEOUT_MS` / `TimeoutFor` / `PROBE_TIMEOUT_MS` / `WaitDevice(1200)` / `ResetServer` 内部 | 调参需改 5 处，易遗漏 | 中 |
| W-08 | JSON 读写 | `ExportPaths()` 正则解析 / `SetExportPath` 手写序列化 / `ExportPathsJson` 手写序列化 | 三段转义规则可能不一致，键含引号时出错 | 低 |

## 二、违反 R2（单一出口）

| 编号 | 问题 | 影响面 |
|---|---|---|
| W-09 | 14 个导出 handler 仍调用 `OutDir(kind)`，依赖线程局部 id + kind 兜底 | 新增导出命令若 kind 与指令名不一致，需同时登记两处才生效 |

## 三、违反 R8/R9（命令行传参与外部输入）

| 编号 | 问题 | 证据 | 影响面 | 严重度 |
|---|---|---|---|---|
| W-11 | `RunAdbRawEx` 接收拼好的字符串，交给命令外壳执行 | 4 处调用（push/pull） | 路径含 `&` `\|` `&&` 时被当命令执行；含空格时依赖手工引号 | **高** |
| W-12 | 设备号以字符串拼接进入命令行 | `"-s " + …` 出现 16 次 | 序列号异常时参数错位 | 中 |
| W-13 | 包名/路径拼接进 shell 命令 | 13 处 | 包名含特殊字符时命令解析错误或注入 | 中 |
| W-14 | `pkill -f 'logcat -f'` 引号嵌套拼串 | 3 处 | 变量含引号时注入 | 中 |
| W-15 | 导出路径未做合法性校验 | `SetExportPath` 直接落盘 | 可指向 `C:\Windows`、磁盘根、UNC；写满磁盘或覆盖系统目录 | **高** |
| W-16 | 硬编码绝对路径 67 处 | 各 Cmd 文件 | 换机器/换盘符即失效，测试与真实环境不一致 | 低 |

## 优先级建议（不修复，仅排序）

1. **W-11 / W-15**：注入与路径越界，安全面
2. **W-17**：齿轮不可见，功能入口直接丢失
3. **W-01 / W-02**：截图两套实现，其中一套不可用
4. **W-04 / W-09**：导出目录多来源，易回归
5. **W-03 / W-07 / W-05**：一致性债，随功能增加而放大
6. 其余：清理类（W-20/21/22/24）
