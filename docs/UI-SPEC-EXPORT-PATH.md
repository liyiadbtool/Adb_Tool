## 0. 两个入口，两种形态，同一份数据

```
入口 A  设置页 →「导出路径」→ 完整弹窗（选指令 + 设路径 + 删除）
入口 B  指令卡片右上角 ⚙ → 轻量弹窗（只有一个路径输入框）
数据    两处读写同一份 export_paths.json，互相同步
```

## 1. 入口 A：设置页（完整模式）

### 1.1 打开时

```
┌──────────────────────────────────────────────┐
│ 指令  [ 一键截图并立即打开 (shotopen)  ▼ ]   │  ← 下拉，不是输入框
│                                              │
│ 路径  [ D:\导出\截图                    ]     │
│       [浏览…]  [保存]  [删除]  [关闭]         │
├──────────────────────────────────────────────┤
│ 已设置：                                     │
│  apk      → D:\导出\APK                      │
│  dlog     → \\nas\logs                       │
└──────────────────────────────────────────────┘
```

### 1.2 下拉菜单内容

- 列出**全部导出类指令**（16 条：截图 / 录屏 / 各类日志 / APK / ANR / crash …）
- 每项显示：`中文名（指令名）`
- **已设置的条目带绿点 + 路径摘要**（如 `apk → D:\导出\APK`）
- 未设置的显示「未设置」
- 默认选中上次选中的项（无记忆则选第一项）

### 1.3 选择指令后

- 路径输入框**自动填入该指令当前的导出路径**（未设置则为空，placeholder 提示默认目录）
- 底部列表同步高亮当前项

### 1.4 保存

```
① 校验：绝对路径 / 非磁盘根 / 非系统目录（沿用 CheckExportPath）
② 写 export_paths.json
③ 刷新下拉里的绿点与底部列表
④ toast「已保存」
⑤ 弹窗保持打开（便于连续配置）
```

### 1.5 一键删除

- 按钮置于「保存」旁，**只清除当前选中指令**的映射
- 清除后：输入框清空、绿点消失、该指令回到默认目录
- 需二次确认（`确定删除 shotopen 的自定义路径？`）—— 防误点
- 删除 ≠ 清空保存：删除是显式动作，空路径保存按「恢复默认」处理（两者效果相同，但语义清晰）

### 1.6 再次打开

- 弹窗显示**上次所选指令 + 已保存的路径**
- 即“设置完后再次调起，能看到当前设置”

## 2. 入口 B：卡片 ⚙（轻量模式）

### 2.1 打开时

```
┌───────────────────────────────┐
│ 一键截图并立即打开             │  ← 只读标题（指令已确定）
│ [ D:\导出\截图          ]      │  ← 唯一输入框
│ [浏览…] [保存] [删除] [关闭]   │
└───────────────────────────────┘
```

- **不出现指令选择**（点哪张卡就是哪条指令）
- **不出现指令名输入框**（原来可编辑，易填错，取消）
- 显示该指令**当前已设置的路径**（未设置则空 + placeholder 默认目录）

### 2.2 保存 / 再次点击

```
保存 → 写同一份 json → 设置页下次打开即可看到 → 该卡片 ⚙ 变绿 + 绿点
再次点 ⚙ → 输入框回填已保存路径 → 可直接修改覆盖
```

### 2.3 同步规则

| 操作 | 卡片 ⚙ | 设置页 | 生效时机 |
|---|---|---|---|
| 卡片里保存 | 绿点出现 | 下拉+列表同步 | 立即可见；设置页已打开则实时刷新 |
| 设置页保存 | 绿点出现 | 列表更新 | 同上 |
| 设置页删除 | 绿点消失 | 列表移除 | 同上 |

**实现要点**：任何一端写入后，主动向另一端推送一次最新映射（`{kind:'outpath', act:'list'}`），不依赖下次打开。

## 3. 与现状的差异（改动点）

| 项 | 现状 | 目标 |
|---|---|---|
| 设置页选指令 | 手输指令名（易错） | 下拉选择 |
| 设置页删除 | 无 | 一键删除 + 二次确认 |
| 设置页回显 | 打开时列表有，输入框空 | 选中项自动回填路径 |
| 卡片 ⚙ 弹窗 | 与设置页同一个大弹窗（含指令名输入框） | 独立轻量弹窗，只有一个路径框 |
| 卡片再次点击 | 能看到列表但不直观 | 输入框直接回填当前值 |
| 两端同步 | 保存后各自刷新 | 写入即双向推送 |
