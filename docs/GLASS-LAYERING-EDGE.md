# 玻璃界面分层方案：对齐 Edge 浏览器的层级模型（仅记录，未改代码）

> 记录时间：2026-11-28 13:41
> 背景：当前玻璃主题是"所有层都半透明"，导致内容区对比度不稳、层次靠阴影堆。
> 提出：参照 Edge（Mica + Acrylic）的分层方式重排。

---

## 一、Edge 的实际分层（观察结论）

```
L0  窗口底        Mica / Acrylic —— 桌面模糊后的颜色，整窗一张
L1  标题栏 + 页签  半透明（比 L0 稍亮），与窗口底融合，底部 1px 分隔线
L2  工具栏/侧栏    与 L1 同材质，靠分隔线与内容区分开，不做独立卡片
L3  页面内容       不透明（白 / 深底）—— 关键：内容层不透
L4  浮层（菜单）   Acrylic，比内容层更透，圆角 8px + 大阴影 + 边缘亮线
L5  模态遮罩       黑 32% + 面板（比 L4 更实）
```

**两条核心规则**

1. **只有两种材质**：窗口底（Mica，模糊强、透明度低）与浮层（Acrylic，透明度高、带阴影）。
   中间的内容层**不透明**——这是 Edge 读起来干净的原因。
2. **层级靠 1px 分隔线与亮度差表达，不靠阴影**。
   一屏里最多一条投影（浮层），其余全是线。

---

## 二、映射到本工具

| 层 | 本工具对应 | 材质 | 透明度 | 说明 |
|---|---|---|---|---|
| L0 | 窗口底（DWM Acrylic） | Mica/Acrylic | 桌面可见 | 已有（仅玻璃主题） |
| L1 | 标题栏 `.tb` + 页签 | 玻璃 | `.55` + blur 30 | 与窗口底融合，底部 1px `--rim` |
| L2 | 左侧导航 `.qnav` | 玻璃 | `.40` + blur 24 | 右侧 1px 分隔线，**不做圆角卡片** |
| L3 | 内容区 `.quick-body` / 终端 / 日志 | **不透明** | `1.0`（白 `#FBFCFE` / 深底） | 保证命令、日志、表格的对比度 |
| L4 | 弹窗 `.v15-pop` / `.wadb-pop` / `#cf-panel` | 玻璃 | `.72` + blur 40 | 已有，保留 |
| L5 | 模态遮罩 `.cf-mask` / `#op-backdrop` | scrim | 黑 32% | 面板 `.88` |

**关键改动点（与现在的差异）**

```
① 内容区从 .24 提高到接近不透明 —— 现在是"能看见桌面但字发灰"
② 卡片不再各自是玻璃，改成"内容层上的浅色块 + 1px 边"
   （Edge 里没有"每张卡都是玻璃"这种东西）
③ 导航与标题栏合并为同一材质带，去掉两者之间的投影
④ 全屏只保留 1 处大投影（浮层），其余用线
```

---

## 三、这样做的收益与代价

**收益**

```
· 文字对比稳定（内容层不透），日志/终端可读性回到深色主题的水平
· 层次一眼可读：窗口(桌面) → 框架(玻璃) → 内容(实) → 浮层(玻璃)
· 性能可控：大面积 blur 只出现在标题栏/导航/浮层，不覆盖滚动内容
· 与用户"Edge 那种分层"的心理预期一致
```

**代价**

```
· 内容区不透 → 玻璃感集中在边框与浮层，比现在"弱"
  缓解：给内容层 0.96 而非 1.0，仍能透一点点
· 需要重排样式作用层级（.quick-body / .qcard / .qnav），改动面中等
```

---

## 四、可选：沉浸度三档（替代单一透明度滑块）

```
克制   内容层 .98   标题栏 .62   导航 .52   浮层 .78   ← 接近 Edge 默认
平衡   内容层 .92   标题栏 .55   导航 .42   浮层 .72   ← 建议默认
沉浸   内容层 .82   标题栏 .45   导航 .30   浮层 .64   ← 接近当前效果
```

滑块若保留，改名为「沉浸度」，同时驱动四个 alpha（按固定比例），
而不是只改一个变量导致层次全乱。

---

## 五、落地顺序（若后续要做）

```
1. 抽出层级令牌：--l1-a / --l2-a / --l3-a / --l4-a（替换现有 --glass-a 单值）
2. 内容层改近不透明，卡片改"浅色块 + 1px 边"（去 backdrop-filter）
3. 标题栏与导航合并材质，去掉两者之间的投影，只留 1px 分隔
4. 全屏只保留浮层大投影
5. 截图对比三档沉浸度，再决定默认值
```

**不做**：给每张卡片单独玻璃、内容区大面积 blur（Edge 本身也不这么做）。
