## 四、新设备的认证前提（最容易卡住的一步）

仓库是 **Private**，新设备要能 `clone` / `push`，二选一：

- **SSH**（推荐）：新设备 `ssh-keygen` 生成自己的 key，把公钥贴到 GitHub → Settings → SSH and GPG keys。
- **HTTPS + PAT**：`https://github.com/liyiadbtool/Adb_Tool.git`，首次操作时用 Personal Access Token（不是密码）。

> 如果新设备用**别人的 GitHub 账号**，需要你在仓库 Settings → Collaborators 里把那个账号加进去。


## 六、改代码前必须知道的三条硬规则（摘自 AGENTS.md）

1. **C# 是 5.0，别写新语法**：`$"{x}"`、`?.`、`nameof`、`out var` 都会编译不过。共用代码（如 `Prefix.cs`）里**不能出现 `Color` 类型**（CLI 那个 exe 不引用 System.Drawing，会出现 CS0234），只返回 `int`（0xRRGGBB）。

2. **前端是"分层注入"**：`ui.html` 里 V14~V17 四段由 `_vNN.js/.css` 生成。要改这几段 → 改 `_vNN` 源文件，再按顺序重注：
   ```bash
   python _inject_v14.py && python _inject_v15.py && python _inject_v16.py && python _inject_v17.py
   ```
   强调色的 `--accent` 由 `_gen_accent.py` 生成，改色值后要 `python _gen_accent.py` 重新生成。
   标记**外面**的部分（页面骨架、A13 标题栏）可以直接改 ui.html。

3. **门禁不许绕过**：`verify_all.py` 26 项必须全绿才 commit。红了不许改断言——要么改代码，要么在 `_gate_invariants.py` 里显式登记（新增用 `A18_ADDS`，删除用 `A18_REMOVED`）并写清理由。

## 八、FAQ

- **clone 报 `Permission denied (publickey)`？** 新设备没配 SSH key，或 key 没贴到 GitHub。见 §四。
- **clone 报 `Repository not found`？** 要么仓库名/账号拼错，要么新设备的账号不是这个私有仓库的协作者。见 §四。
- **图标还是旧的？** Windows 图标缓存问题。右键任务栏该图标 → 取消固定 → 重新固定；或重启资源管理器。
- **本机用户名是中文（`C:\Users\李亦`）**：不要在任何 .bat 里拼含中文的绝对路径，脚本里一律用 `%~dp0`。
