## 五、改代码前必须知道的三条硬规则（摘自 AGENTS.md）

1. **C# 是 5.0，别写新语法**：`$"{x}"`、`?.`、`nameof`、`out var` 都会编译不过。共用代码（如 `Prefix.cs`）里**不能出现 `Color` 类型**（CLI 那个 exe 不引用 System.Drawing，会出现 CS0234），只返回 `int`（0xRRGGBB）。

2. **前端是"分层注入"**：`ui.html` 里 V14~V17 四段由 `_vNN.js/.css` 生成。要改这几段 → 改 `_vNN` 源文件，再按顺序重注：
   ```bash
   python _inject_v14.py && python _inject_v15.py && python _inject_v16.py && python _inject_v17.py
   ```
   标记**外面**的部分（页面骨架、A13 标题栏）可以直接改 ui.html。

3. **门禁不许绕过**：`verify_all.py` 26 项必须全绿才 commit。红了不许改断言——要么改代码，要么在 `_gate_invariants.py` 里显式登记（新增用 `A18_ADDS`，删除用 `A18_REMOVED`）并写清理由。

## 八、FAQ

- **图标还是旧的？** 不是代码问题（已换成黑白灰）。右键任务栏该图标 → 取消固定 → 重新固定；或重启资源管理器刷新图标缓存。
- **push 报 `Repository not found`？** 仓库还没建，去 https://github.com/new 建 `Adb_Tool`（私有，别勾初始化）。
- **push 报 `Permission denied`？** 公钥没生效，去 GitHub → Settings → SSH and GPG keys 重新贴。
