# adb_log_export GUI 版

图形界面的日志导出工具，与命令行版 `adb_log_export.exe` **共用同一批源码**，
命令能力完全一致。

界面采用 **WebView2 内嵌 HTML** 渲染（深色主题、现代简洁风格），
不再是老式 WinForms 控件。

---

## 一、怎么用

双击 **`adb_log_gui.exe`** 即可。

**运行依赖**：
1. .NET Framework 4.x（Win10/11 自带）
2. **Microsoft Edge WebView2 Runtime**（Win10/11 通常自带；若工控机缺它，
   会弹窗提示安装，装一次即可，下载：https://developer.microsoft.com/microsoft-edge/webview2/ ）

本目录里的 `Microsoft.Web.WebView2.Core.dll`、`Microsoft.Web.WebView2.WinForms.dll`、
`WebView2Loader.dll` 是运行时组件，**必须和 exe 放在同一目录**，不要单独移动 exe。

首次运行会自动从上一级目录复制 `adb_log_export.ini` 和 `cmds.ini`，之后各读各的配置。

---

## 二、界面结构

- **顶栏**：应用名 + 设备号 + SOC，右侧帮助/主题切换按钮
- **页签一「指令输入」**：上方大输出区（结果直接看这里），下方输入行（提示符 + 输入框 + 执行/停止/清屏/复制）
- **页签二「快捷指令」**：预留区 + 底部反馈窗口（占窗口高 25%，只显示快捷指令页自己的执行结果）
- **底栏**：连接状态 + 当前目录

**反馈隔离**：指令输入页的报错/成功只显示在上方输出区，不进入快捷指令页的反馈窗口；反馈窗口只记录快捷指令页自己的结果。两页互不串扰。

主题：右上角太阳/月亮图标切换深浅主题。

## 二、两个页签

### 指令输入

命令行版能敲的，这里都能敲，一个一个字符都对得上：

| 输入 | 作用 |
|---|---|
| `ls`、`cd`、`pwd`、`pull`、`push`、`adb`、`shell` | 设备命令，语义与原生一致 |
| `df -h`、`pm list packages`、`cat x.log` | 不认识的裸命令直接透传给设备 |
| `:h`、`:which ls`、`:cmds`、`:env`、`:pkg ver` | 工具自身命令 |
| `!top` | 强制走设备 shell（绕过交互式保护） |
| `cd @logs` | 跳转点 |
| `D:\导出目录` | 把当前目录导出到该路径 |
| `你好` | 直接发给 App（走发送逻辑） |

快捷键：

| 键 | 作用 |
|---|---|
| `Enter` | 执行 |
| `↑` `↓` | 翻历史（和命令行版共用同一个 `.adb_tool_history`） |
| `Ctrl+L` | 清屏 |
| `Esc` | 收回焦点（不执行） |

按钮：**执行** / **停止**（杀掉当前 adb 子进程）/ **清屏** / **复制**（复制当前输入）。

中文输入法下打的**全角冒号** `：`、全角叹号 `！` 会被自动归一化成半角，
和命令行版一致 —— 这是 `NormalizeLead()` 在做，不是界面另写的一套。

### 快捷指令

目前**预留**，中间是占位区，说明后续会放常用指令卡片、一键导出、批量操作。

下方是**执行反馈窗口**，固定占窗口高度的 **1/4**（窗口拉大拉小都保持这个比例）：

| 时间 | 指令 | 结果 | 耗时 |
|---|---|---|---|
| 17:22:03 | `ls` | 成功 | 412 ms |
| 17:22:15 | `not_a_real_cmd` | 失败 | 89 ms |

* 最多保留最近 200 条
* 双击任意一行可复制那条指令
* 没执行过指令时显示一条灰色占位说明

反馈列表记录的是**两个页签共用**的执行历史，所以在这里看到的
就是"刚才在指令输入页做了什么、成没成、花了多久"。

## 三、怎么编译

```bat
build_gui.bat
```

和 `_cs\build.bat` 的**唯一差别**是 `/main:` 指向和 WinForms 引用：

```
命令行版  /main:AdbLogExport.App
图形版    /main:AdbLogExport.Gui.GuiEntry
```

源文件是同一批，一行命令逻辑都没有复制。这是"能力完全保留"的**结构保证**，
不是靠人去同步两份代码。

## 四、三个无头模式（可进 CI）

### `--selfcheck` 布局自检

```bat
adb_log_gui.exe --selfcheck
```

构造真窗体、跑真布局代码、按可判定的数学关系断言，**窗口从不显示**，
所以在没有桌面的机器上也能跑。共 40 项，覆盖：

* 顶栏 / Tab 栏 / 底栏高度
* 两个页签互斥显示
* 输出区占主区 ≥ 70%、与输入行不重叠
* 四个按钮互不重叠、不越界、输入框在按钮左侧
* 反馈窗口占窗口高 1/4（0.19~0.31）
* 输出着色器：颜色级别、动画残片丢弃、CRLF 与 `\r` 的区分
* 输入预处理与命令行版等价（全角归一化、中文不被误改）
* 820×560 与 1400×900 两种极端尺寸下的鲁棒性

退出码 0 = 全过，1 = 有失败项，明细写到 `gui_selfcheck.log`。

### `--exec` 无头执行

```bat
adb_log_gui.exe --exec ":h" ":which ls" "ls"
adb_log_gui.exe --exec-file cmds.txt
```

走的是界面的**真实管道**：`GuiBoot` 初始化 → `GuiSink` 接管 Console →
`App.Dispatch` 分派，不是另开一条捷径。每行输出渲染成 `L<级别> <文本>`，
级别就是界面着色的语义标签（1=成功 2=失败 3=警告 4=弱化 5=路径 0=普通）。

用途：程序化验证"界面能不能做命令行同样的事"。

### 等价性验证脚本

在上一级目录：

```bat
python verify_gui_equiv.py
```

同一串命令分别喂给两个 exe，把文字归一化后逐行比对。
退出码 0 表示**命令行的每一行输出，GUI 都能产出**。

## 六、与命令行版的已知差异

这些差异都是**外壳**层面的，不涉及命令能力：

1. **没有控制台提示符行**。命令行是 `746f2719 > ls` 打一行，
   界面把提示符放在输入框左侧常驻，回显单独打一条。
2. **启动横幅不占输出区**。命令行无设备时会打一屏"离线可用命令"指引；
   界面把同样的信息放进顶栏状态和底栏提示。
3. **退出方式**。命令行是 `:q` 或 Ctrl+C；界面直接关窗口。
4. **Ctrl+C 不可用**。中断当前操作请点「停止」按钮。
